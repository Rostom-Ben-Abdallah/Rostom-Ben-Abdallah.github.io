01 / PROJECT OBJECTIVES

Language, perception and navigation in one robot.

The project was designed around four connected capabilities: intuitive natural-language control, structured visual scene understanding, autonomous mapping/navigation and a unified operator interface.

01

Natural-language teleoperation

Ollama/Llama 3.1 interprets commands and produces bounded motion values such as linear speed, angular speed and duration for ROS 2 control.

02

YOLO + LLM scene understanding

A YOLOv8n scene node processes the RGB stream and exposes /describe_scene for structured JSON plus /explain_scene for natural-language interpretation.

03

SLAM & waypoint navigation

slam_toolbox builds the environment map from LiDAR and transforms, while Nav2 executes navigate_to_pose goals from predefined waypoints.

04

Integrated PyQt GUI

The operator dashboard combines LLM command entry, direct robot controls, map/position visualization and the live camera feed.

02 / ARCHITECTURE

A ROS 2 graph built around explicit interfaces.

Rather than treating the LLM as the robot controller, the system separates language, perception, navigation and safety into ROS 2 nodes communicating through topics, services and actions.

03 / RESULTS

From isolated components to an integrated demo.

The final presentation reports working natural-language control, ROS 2 Navigation2 integration, a low-latency GUI camera stream and successful integration of AI, robotics and the operator interface.

Intuitive teleoperation

Natural-language commands were translated into executable robot movement behavior.

NAVIGATION

Functional Nav2 stack

Waypoint goals could be sent through the Navigation2 navigate_to_pose action.

INTERFACE

Real-time GUI video

The PyQt dashboard provided live visual context alongside robot controls and map information.

INTEGRATION

AI + robotics synergy

The project demonstrated how local language inference, perception and ROS 2 autonomy can share a single workflow.
